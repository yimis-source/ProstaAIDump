# Registros TSP

| Archivo | Contenido | Responsable |
|---|---|---|
| `cicloN_lanzamiento.md` | Plan del ciclo: objetivos, tareas, horas estimadas, plan de calidad y riesgos | Gerente de planeación |
| `cicloN_postmortem.md` | Cierre del ciclo: plan frente a real, defectos, valor ganado y lecciones | Gerente de planeación |
| `LOGD_registro_defectos.md` | Registro de defectos de todo el proyecto | Gerente de planeación (registra), todos (reportan) |
| `LOGT_registro_tiempos.md` | Horas por integrante y tarea | Gerente de planeación (consolida), todos (reportan) |
